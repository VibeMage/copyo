Paster

Support & help · 支持与帮助

English 中文

Paster is an open-source clipboard history manager for macOS. Everything you copy is kept on your Mac, and one keyboard shortcut brings any earlier item back. No account, no telemetry, no servers.

Quick start

  1. Paster lives in the menu bar (the clipboard icon in the top-right corner). It has no Dock icon and no main window.
  2. Copy anything in any app. It shows up in Paster automatically.
  3. Press ⇧⌘V or click the menu bar icon to open the clipboard panel. Type to search, use ← → to move, Space to preview.
  4. Press Return to put the selected item back on the clipboard. The panel closes and you're back in the app you were using, so just press ⌘V.
  5. Right-click a card to pin it to a Pinboard, copy it as plain text or delete it. Settings are behind the gear button in the panel, or right-click the menu bar icon.

FAQ

Pressing Return doesn't paste anything. Is that a bug?

No. Return puts the item on the clipboard, closes the panel and returns you to the app you were using; press ⌘V to paste. Paster deliberately never types into other apps, which is also why it needs no special permissions.

Does Paster need any system permissions?

No. Paster asks for neither Accessibility nor Input Monitoring, and it never watches what you type in other apps. The ⇧⌘V shortcut uses the standard system hotkey API. If you choose iCloud sync, it uses the Apple account already signed in on your Mac.

How do I change the shortcut?

Settings → Shortcuts → click the current shortcut and press a new combination. It must include ⌘, ⌥ or ⌃. “Reset” restores ⇧⌘V.

Where is my data stored? Does anything leave my Mac?

Everything stays on your Mac: the App Store version keeps its data in ~/Library/Containers/dev.vibemage.Paster/, the direct-download version in ~/Library/Application Support/Paster/. Paster has no analytics, no crash reporting and no servers of its own. See the privacy policy.

How does sync between my Macs work?

Settings → Sync. You can either point Paster at a folder you choose (for example a folder inside iCloud Drive or another synced drive), or use your own iCloud account. In both cases the data is stored with the provider you picked; it never passes through a server run by us.

Something I copied doesn't appear in the history.

Content that apps mark as concealed or transient (passwords from password managers, for example) is skipped on purpose and never recorded.

How do I delete items or clear the history?

Select a card and press ⌘⌫, or right-click it and choose Delete. The history limit and “clear history” are in Settings → Clipboard. Pinned items on Pinboards are not affected by history cleanup.

How do I uninstall Paster completely?
  1. Quit Paster (right-click the menu bar icon → Quit).
  2. Move Paster.app to the Trash (or delete it from Launchpad for the App Store version).
  3. Delete the data folder listed above if you want the history removed too.

快速上手

  1. Paster 常驻菜单栏（右上角的剪贴板图标），没有 Dock 图标，也没有主窗口。
  2. 在任意应用里复制任何内容，它会自动出现在 Paster 中。
  3. 按 ⇧⌘V 或点击菜单栏图标呼出面板。直接输入即可搜索，← → 切换卡片，Space 预览。
  4. 按 Return 把选中的条目放回剪贴板。面板随即收起并回到你之前使用的应用，直接按 ⌘V 粘贴即可。
  5. 右键卡片可固定到 Pinboard、以纯文本复制或删除。设置在面板右上角的齿轮按钮里，或右键菜单栏图标。

常见问题

按回车没有粘贴任何内容，是不是坏了？

不是。回车会把条目放回剪贴板、收起面板并回到你之前使用的应用，按 ⌘V 即可粘贴。Paster 有意不向其他应用模拟输入，所以也不需要任何特殊权限。

Paster 需要什么系统权限吗？

不需要。Paster 不申请「辅助功能」和「输入监控」权限，也从不监听你在其他应用中的输入。⇧⌘V 快捷键使用系统标准的全局热键接口。若选择 iCloud 同步，使用的是 Mac 上已登录的 Apple 账户。

怎么修改快捷键？

设置 → 快捷键 → 点击当前快捷键，然后按下新的组合键（必须包含 ⌘、⌥ 或 ⌃）。「重置」可恢复为 ⇧⌘V。

数据存在哪里？会上传吗？

全部保存在本机：App Store 版在 ~/Library/Containers/dev.vibemage.Paster/，直接下载版在 ~/Library/Application Support/Paster/。Paster 没有统计分析、没有崩溃上报，也没有自己的服务器。详见隐私政策。

多台 Mac 之间怎么同步？

设置 → 同步。可以让 Paster 使用你指定的文件夹（例如 iCloud Drive 或其他网盘里的文件夹），也可以使用你自己的 iCloud 账户。两种方式下数据都保存在你选择的服务商那里，不会经过我们的服务器。

有些复制的内容没有出现在历史里。

被应用标记为隐藏或临时的内容（例如密码管理器里的密码）会被有意跳过，永远不会记录。

怎么删除条目或清空历史？

选中卡片按 ⌘⌫，或右键选择删除。历史上限和「清空历史」在 设置 → 剪贴板。固定在 Pinboard 上的条目不受历史清理影响。

怎么彻底卸载 Paster？
  1. 退出 Paster（右键菜单栏图标 → 退出）。
  2. 把 Paster.app 移到废纸篓（App Store 版可在启动台中删除）。
  3. 若也要删除历史记录，删除上面列出的数据目录。
