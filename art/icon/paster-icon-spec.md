# Paster App Icon — 色散卡片 (8a)

选定方向：骨白卡片 + 红蓝双层错位套印，各自发光。错位手法来自印刷套印不准与 RGB 通道分离。
四条内容条代表剪贴板缓存的不同内容类型。

## 颜色

| 角色 | 值 |
| --- | --- |
| 红 · 错位层 | `#FF2D55` |
| 蓝 · 错位层 | `#0A84FF` |
| 卡片 | `#F7F3EA` |
| 内容条 | `#16161A` |
| 底（径向渐变，中心 50% / 16%） | `#1B1620` → `#08060B` |

## 几何（以图标边长为 1）

| 项 | 值 |
| --- | --- |
| 圆角方底 | inset `0.098`，圆角 `0.2237` |
| 卡片 | `0.50 × 0.556`，圆角 `0.078` |
| 卡片位置 | left `0.25`，top `0.222` |
| 错位偏移 | ±`0.030` / ±`0.025` |
| 发光半径 | `0.055`（外扩 ×1.5） |
| 内容条 | 高 `0.052`，间距 `0.048` |
| 条宽 | 100 / 76 / 88 / 60 % |
| 卡片左右内距 | `0.062` |

## 光栅化规则

- 1024 / 512 / 256 / 128 / 64 / 32：同一套比例几何，按 8–16 倍超采样绘制后逐级折半降到目标尺寸。
  直接在小尺寸光栅化会出锯齿。
- 16：**手工重绘**，不走比例缩放。按比例缩时内容条只有 0.67px、错位只有 0.39px，卡片会糊成灰色。
  手工版使用整像素几何（卡片 `8×8` at `4,4`，圆角 `1.4`；错位 ±1px；两条内容条各 1px）。
- 菜单栏模板：**整像素绘制，不做超采样**。模板图标降采会把 1px 描边摊成灰边。
  18 / 36 / 54 对应 @1x / @2x / @3x，纯黑 + 透明，由系统反色。

## 文件

```
icon-master-1024.png            → art/icon-master.png
icon-512/256/128/64/32/16.png   参考用，每档独立生成
appiconset/icon_16x16.png       手工重绘的 16pt，覆盖 make-icon.sh 的产物
menubar-template-18/36/54.png   NSStatusItem 模板图标
```

## 安装

```bash
cp icon-master-1024.png art/icon-master.png
./scripts/make-icon.sh
# make-icon.sh 用 sips 按比例缩，16pt 必糊，最后手动覆盖一次
cp appiconset/icon_16x16.png Paster/Assets.xcassets/AppIcon.appiconset/
```

菜单栏图标需要在代码里以 `isTemplate = true` 加载，系统会按明暗模式自动反色。
