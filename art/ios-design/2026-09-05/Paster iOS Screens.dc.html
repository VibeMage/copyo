组件规格

卡片：整卡 card.tint 底，无边框；头部 = 类型角标（实心来源色胶囊，图标 11 + 文字 11 Semibold）+「来源 · 相对时间」secondary 11 + 可选 pin 图标（已固定）。文本 6 行截断；代码/命令自动识别为等宽；富文本首行加粗；链接 = 标题 3 行 + 域名 accent；颜色 = 80pt 色块 + 等宽色值；图片 = 160pt 缩略图 + 尺寸/格式；文件 = 文件名 + 「仅 Mac」灰标（点按提示到 Mac 上粘贴）。本机条目来源固定「本机」、色 #8E8E93。状态：pressed scale .96；selected 3pt accent 环；focused 2pt accent + 5pt 35% 光晕；drag lift scale 1.04 rotate -2° + 阴影；ghost 35% 透明。

类型角标：6 种（文本 / 富文本 / 链接 / 颜色 / 图片 / 文件），高 20，圆角 10，左内距 6 右 7。

来源色带（1c 中转为整卡淡染）：色 = 同步来的来源色；淡染比例浅 12% / 深 20%；角标即色带的实心表达。

轻提示：玻璃胶囊，高 40，圆角 20，顶部距安全区 6；图标 22 success + 15 Semibold 文字；停留 1.2s。用于「已复制」「已保存」「已固定」。

横幅：卡片底 card，圆角 14，内距 12/14；左 clipboard 图标 accent 24，标题 15 Semibold + 副文 12；右侧系统 UIPasteControl（accent 胶囊「粘贴」）+ 关闭。仅在回到前台且「从其他 App 粘贴」≠ 允许时出现；粘贴后原位替换为「已保存」并 0.4s 后收起。

交互 · 手势 · 动效

轻点卡片：复制到剪贴板 → 卡片 scale .96 → 1（spring 0.35, damping .8）+ 顶部「已复制」轻提示 + 轻触感（.success）。

长按：系统上下文菜单，预览为卡片本体放大 1.04；菜单项：复制 / 纯文本复制 / 分享 / 固定到 Pinboard（子菜单列 Pinboard）/ 删除。

左滑：删除（红，全滑直接删）；右滑：固定到默认 Pinboard（蓝，全滑立即固定并轻提示「已固定」）。

详情：从卡片 zoom 转场（iOS 18+ navigationTransition .zoom）；返回手势同。

面板出现：无全局呼出；App 冷启动直接落历史页；一键保存唤起时历史顶部新卡片从 y −12 / 0 透明淡入并短暂 focused 环 0.8s，同时「已保存」提示。

回到前台：若「允许粘贴」= 允许，静默读取、有新内容则新卡片插入顶部（同上动效）；否则显示横幅（从 −8 下滑淡入 .25s）。

iCloud 状态：右上玻璃胶囊：已同步 / 同步中（图标 1s 旋转）/ 未同步（点按去设置）。

iPad：单指拖卡片到旁边 App = 系统拖放，提供 text / rtf / url / image / color 多表示；硬件键盘 ↑↓←→ 移焦、↵ 复制、⇧↵ 纯文本、空格 Quick Look、⌘F 搜索、⌘P 固定、⌫ 删除、⌘1-3 切侧栏。宽度 < 600pt（Slide Over / 1/3 分屏）切到 iPhone 布局。
